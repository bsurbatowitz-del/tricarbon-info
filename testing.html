Install

  1. Accept the TestFlight invitation e-mail (or the link you received).
  2. Install TestFlight on your iPhone and open TriCarbon from it.
  3. New builds arrive automatically; TestFlight shows "What to Test" for each one.

What to test in 1.3.2

  • New: the app tells you when a newer version is available (at most one check a day of the public version list; nothing about you is sent)

Install the update, open the app and wait a few seconds: no banner should appear, because 1.3.2 is the newest version. The banner ("Version X is available" with Update and an x) appears only when a newer version is live; Update opens the App Store page and x hides it for that version. Switch the language to Montenegrin and check the app as usual. Everything else works as in 1.3.1.

Step by step

TriCarbon is an offline calculator for the carbon footprint of triathlon and multisport events, with an ISO 14001 environmental aspects register.

No login, no account, no network features (it only checks once a day whether a newer version is available), no in-app purchases, no ads, no analytics. Everything the user enters stays on the device.

How to try it:
1. Event tab: tap the folder icon → Load sample event (or More → Load sample event).
2. Results tab: totals per competitor, spectator, personnel and event, charts, recommendations; export PDF or Excel.
3. Inventory tab: tap a line to edit it, + to add one, ••• → Travel estimator.
4. ISO 14001 tab: aspects register with significance scoring.
5. More → Settings: language (English / Montenegrin) and appearance (Automatic / Light / Dark).

Emission factors are indicative defaults and editable in More → Factor library.

Report a problem

In TestFlight take a screenshot and tap Share Beta Feedback, or e-mail b.surbatowitz@icloud.com with the build number (More → About) and, if possible, the exported event file.
