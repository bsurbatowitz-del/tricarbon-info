Please test: Export a PDF, an Excel file and a JSON file from the sample event, in English and in Montenegrin. Importing these files back into TriCarbon still works. The condition itself is on www.trisport.me/tricarbon/.

Windows 1.3.0 – first Windows version

  • First Windows version of TriCarbon – the same calculations, exports and files as the Ubuntu and iPhone apps
  • Light / Dark / Automatic theme (View menu); Automatic follows the Windows app mode, including the title bar
  • Events are saved in Documents\TriCarbon\events, settings in %APPDATA%\TriCarbon
  • PDF reports print Montenegrin letters (č ć đ š ž) with the Windows Segoe UI font
  • Microsoft Store package (.msix), installer (.exe) and portable ZIP

1.3.0

  • Emission factors updated to the official UK 2026 values where they could be checked (travel, flights, fuels, electricity, water, waste, freight); unchecked rows are labelled
  • About 70 new inventory items: more food and drink, flight classes, metro, minibus, e-bike, helicopter and boat fuel, wetsuits, tents, stages, barriers, bike racks, timing, LED screens, pool hire, live stream, more recycling routes
  • Because factors changed, the sample event now totals 76.15 t (was 82.95 t); your saved events keep their own factors until you choose Re-apply to inventory
  • English is now the default language; Montenegrin is one tap away in the language menu
  • Link to the TriSport website (www.trisport.me)
  • This What's new screen, shown once after each update

1.1.0 – first iPhone version (TestFlight build 7)

  • First iPhone version of TriCarbon (same calculations as the Ubuntu app – results are identical)
  • Event tab: event details, competitors, spectators, staff, volunteers, officials, base year and per-competitor target
  • Inventory tab: about 110 ready-made items plus your own lines; travel estimator
  • ISO 14001 tab: aspects register with severity × likelihood scoring and significance
  • Results tab: per competitor, per competitor + spectator, per spectator, per staff/volunteer, per person and event totals; charts, uncertainty, recommendations
  • Export PDF / Excel (English or Montenegrin), Power BI CSV, CSV, JSON, event file; import CSV / Excel / JSON
  • Saved events, editable emission factor library
  • Settings: language English / Crnogorski, appearance Automatic / Light / Dark
