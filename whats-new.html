1.1.0 – first iPhone version (TestFlight build 7)

  • First iPhone version of TriCarbon (same calculations as the Ubuntu app – results are identical)
  • Event tab: event details, competitors, spectators, staff, volunteers, officials, base year and per-competitor target
  • Inventory tab: about 110 ready-made items plus your own lines; travel estimator
  • ISO 14001 tab: aspects register with severity × likelihood scoring and significance
  • Results tab: per competitor, per competitor + spectator, per spectator, per staff/volunteer, per person and event totals; charts, uncertainty, recommendations
  • Export PDF / Excel (English or Montenegrin), Power BI CSV, CSV, JSON, event file; import CSV / Excel / JSON
  • Saved events, editable emission factor library
  • Settings: language English / Crnogorski, appearance Automatic / Light / Dark
